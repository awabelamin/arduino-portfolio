# Media

Put photos, GIFs, and short demo clips here, one subfolder per project:

```
docs/media/
├── line_follower/
├── obstacle_avoiding_car/
├── blind_stick/
└── ...
```

Tips:
- Keep each file under ~10 MB (GitHub's web upload limit is 25 MB). Use GIFs or compressed MP4s.
- For long videos, upload to YouTube or LinkedIn and link them from the project README.
- One clear photo of the circuit + one GIF of it working is usually enough.
